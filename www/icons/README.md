# Daybreak icon pack

The three SVG files share the same 48 by 48 view box and can be resized without
losing detail.

- `daybreak-icon-dark.svg` places the original Daybreak mark on a dark rounded
  tile for app launchers and bookmarks.
- `daybreak-icon-transparent.svg` places the color mark on a transparent
  background for documents and light surfaces.
- `daybreak-icon-mono.svg` uses `currentColor` for one-color printing, toolbar
  buttons, and systems that apply their own foreground color.

The mark is the same sun-and-highlight symbol used in the Daybreak header. Keep
a clear margin of at least one eighth of the icon width around it and do not stretch it out of
proportion.
